# NovusAdventureLevel

Plugin Minecraft cung cấp hệ thống Adventure Level và các tính năng Bí Cảnh.

> **Phiên bản:** 1.1.1  
> **Java:** 21  
> **API mục tiêu trong metadata JAR:** Paper API 1.21

## Cài đặt

1. Dừng máy chủ Minecraft.
2. Tải file `NovusAdventureLevel-1.1.1.jar` từ mục Releases của repository.
3. Đặt JAR vào thư mục `plugins/`.
4. Khởi động máy chủ và kiểm tra console để xem plugin có nạp thành công không.
5. Nếu plugin tạo thư mục cấu hình, hãy dừng server trước khi chỉnh sửa các file đó rồi khởi động lại.

## Lệnh

| Lệnh | Mô tả |
|---|---|
| `/capmaohiem` | Lệnh liên quan đến Cấp Mạo Hiểm |
| `/bicanh` | Lệnh Bí Cảnh |
| `/adminbicanh` | Lệnh quản trị Bí Cảnh |

Cú pháp phụ, quyền yêu cầu và hành vi chi tiết cần được xác nhận từ plugin đang chạy hoặc tài liệu kèm theo bản build. Xem [Command Reference](docs/commands.md).
